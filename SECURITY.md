# Security policy

This repository contains the static marketing site for Druks. It has no backend,
no user accounts and no stored data, so the attack surface is small. Even so,
things like dependency vulnerabilities, unsafe third party scripts or content
injection are worth reporting.

If your report concerns the Druks platform rather than this website, please use
the [main Druks repository's security policy](https://github.com/czpython/druks/blob/main/SECURITY.md) instead.

## Reporting a vulnerability

Do not open a public issue. Use the private GitHub
[security advisory form](https://github.com/czpython/druks-web/security/advisories/new)
and include this information:

- The affected commit or the date you observed the problem on druks.ai
- The impact
- The reproduction steps
- A suggested mitigation, if you have one.

We will acknowledge the report within five business days. We will keep the
report private during validation and repair, and agree a disclosure date with
you. Please do not disrupt the live site during your investigation.
