# Getting help

Thanks for using Druks! Here is where to go depending on what you need.

- **Questions about using Druks itself** are best answered by the [documentation](https://docs.druks.ai/). If the docs don't cover it, open an issue in the [main Druks repository](https://github.com/czpython/druks/issues).
- **Something wrong on the druks.ai website** (a typo, a broken link, a layout problem, an accessibility issue) belongs here. Open an [issue](https://github.com/czpython/druks-web/issues/new/choose) and pick the template that fits.
- **Want to improve the website?** Have a read of the [contributing guide](CONTRIBUTING.md). Small fixes are very welcome.
- **Security concerns** should never go in a public issue. See [SECURITY.md](SECURITY.md).

If you are not sure which of these applies, open an issue here anyway and we will point you in the right direction.
